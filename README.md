# Type Doom Game

A small typing game built with [Phaser 3](https://phaser.io) and Vite. You type a magic word before the monster reaches you.

<img src="https://raw.githubusercontent.com/felipedfe/felipedfe/refs/heads/main/assets/type-monster-frame-2.png" alt="" />

## Run locally

```bash
npm install
npm run dev
```
